# Snack Meet privacy policy

Snack Meet is local-first. Recordings, transcripts, summaries and local-model processing remain on the user's device unless the user explicitly configures an external API or sync location.

API credentials are stored in macOS Keychain. Snack Meet does not send analytics to the former upstream project and does not check its update servers.

When an external model provider is selected, the content required for that operation is sent directly to the endpoint configured by the user and is subject to that provider's policy.
